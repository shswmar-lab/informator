# Автоинформатор — редактор `p.txt`

HTML-редактор для файла `p.txt` — данных маршрутов, остановок и служебных объявлений бортового автоинформатора (кодировка Windows-1251, CRLF).

## Файлы

| Файл | Назначение |
|---|---|
| `p-editor.html` | Редактор `p.txt` (одностраничный, работает офлайн в браузере) |
| `p.spec.md` | Формальная спецификация формата `p.txt` |

## Возможности редактора

- Импорт и экспорт `p.txt` (Windows-1251);
- загрузка папки `s` с аудиофайлами (`.wav`) и проверка соответствия токенов;
- валидация данных и отчёт об ошибках/предупреждениях;
- вкладки «Маршруты», «Конечные», «Спецрежимы», «Отчёт»;
- отмена/возврат действий, поиск по остановкам и токенам.

## Формат `p.txt`

Три секции, идущие строго по порядку и разделённые шестью строками `~`:

- **A — маршруты:** заголовок `|*N*^Имя` и строки остановок `#(lat,lon)(lat,lon)Имя^Сценарий`;
- **B — конечные для табло:** заголовок `|N^Имя` и строки `#Текст`;
- **C — спецрежимы:** заголовок `|@-Имя` и записи `Имя^Сценарий`.

Маркеры: `|` `*` `@` `-` `#` `^` `,` `\` `(` `)` `~`. Подробности — в `p.spec.md`.
